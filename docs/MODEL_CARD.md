## Interpretation and intended use

- **The model has no detectable predictive signal on this dataset.** Test ROC-AUC's confidence interval contains 0.5 and the permutation test cannot distinguish it from models trained on random labels. Every candidate — including gradient boosting and leakage-safe history features — lands in the same place.
- Profiling agrees: no booking-time field moves the late rate by more than a few points (see `docs/DATA_QUALITY.md` → `planned_transit_outlier_for_route`; same-lane transit times vary 3–35 days).
- Probabilities are **not calibrated** (class-balanced training centres them on 0.5). Use the risk band as a *relative* signal at most; do not use the probability as a true likelihood.
- **Not suitable for automated decisions.** It is shipped to prove the serving, monitoring and leakage boundaries end-to-end; the same pipeline will pick up signal as soon as better features exist.
